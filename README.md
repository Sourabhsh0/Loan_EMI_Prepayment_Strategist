# Loan & EMI Prepayment Strategist

A beginner-friendly personal finance web project built with:
- HTML
- CSS
- Vanilla JavaScript

## Features
- EMI calculation
- Total interest calculation
- Monthly extra-payment strategy
- One-time prepayment
- New loan tenure calculation
- Interest saved calculation
- Months saved calculation
- Amortization schedule
- CSV download
- Responsive mobile design

## How to run
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Or use VS Code + Live Server.
